# Soundbed

Pads contínuos para louvor, direto no navegador. PWA feito com Vite, React, TypeScript e Web Audio API.

## Recursos
- 24 tons (12 maiores e 12 menores) com pads sintetizados no aparelho (sem arquivos de áudio)
- Troca de tom com crossfade configurável
- 4 timbres, volume, reverb e brilho
- Setlists salvas no aparelho
- Funciona offline (service worker)

## Rodar
```bash
npm install
npm run dev     # desenvolvimento
npm test        # testes
npm run build   # build de produção em dist/
```
